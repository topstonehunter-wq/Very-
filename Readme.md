# 🌈 WAXTIX - Mobile-First Social Media Platform

WAXTIX is a high-performance, dark-themed, mobile-first social network built with HTML5, Tailwind CSS, JavaScript, and Firebase Realtime Database integration.

---

## ⚡ Features

- **Short Videos (Reels):** Vertical snap scrolling feed with verified user badges, watermark tags, like counts, and audio indicators.
- **News Feed:** Instant news cards with tag filters and interaction buttons.
- **Real-Time Translated Chat:** Built-in Firebase RTDB listener with auto-translation toggle support.
- **Drag & Drop Uploader:** Simulated bucket upload pipeline for public video and image assets.
- **User Profiles:** Stats tracker, user bio, and video grid layout.

---

## 🛠️ Stack Architecture

- **Frontend:** Single-file HTML5, Tailwind CSS (Play CDN), FontAwesome icons, Inter typography.
- **Backend/Database:** Firebase Realtime Database (`https://waxtix-3cc19-default-rtdb.firebaseio.com/`).
- **Deployment:** Render Static Site Hosting / GitHub Pages.

---

## 🚀 How to Deploy on Render

1. Create a repository on GitHub named `waxtix`.
2. Add `index.html` and `README.md` to your repository root.
3. On Render, select **New +** -> **Static Site**.
4. Connect your GitHub repository (`waxtix`).
5. Set **Publish Directory** to `.` (dot) and click **Create Static Site**.
